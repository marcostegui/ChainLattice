Facilitates distributed transaction management and real-time data processing across a hybrid, scalable service manager architecture.

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainLattice.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure ChainLattice, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
